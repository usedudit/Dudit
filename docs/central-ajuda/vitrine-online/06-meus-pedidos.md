# Meus Pedidos na Vitrine Online

A seção **Meus Pedidos** reúne todos os pedidos que você fez na Vitrine Online. É o lugar para acompanhar o status, ver detalhes, pagar eventuais pendências e, no momento certo, avaliar o que comprou.

[IMAGEM: Tela da listagem de pedidos mostrando cards com status e resumo]

Legenda: Cada pedido mostra o vendedor, itens, valores e status atualizados em tempo real.

## Como acessar

Na Vitrine Online, basta clicar em **Meus Pedidos** no cabeçalho ou no menu da sua conta. Você precisa estar **logado** para visualizar seus pedidos.

## Como os pedidos são organizados

Os pedidos apareçam em ordem da **data mais recente** para a mais antiga. Você pode filtrar por abas:

| Aba | O que mostra |
| :--- | :--- |
| **Todos** | Todos os pedidos, independente do status |
| **Aguardando pagamento** | Pedidos com status Pendente |
| **Preparando** | Pedidos pagos, em separação/produção ou prontos para retirada |
| **Enviado** | Pedidos já despachados, a caminho ou entregues |
| **Entregue** | Pedidos concluídos |

Cada aba mostra o **número de pedidos** entre parênteses, atualizado automaticamente.

## Status de pagamento

O **status de pagamento** indica se o dinheiro já foi recebido pelo vendedor:

| Status | O que significa |
| :--- | :--- |
| **Pago** | O pagamento foi confirmado. O pedido seguirá para a fase de preparo e entrega. |
| **Pendente** | O pagamento está aguardando confirmação (Pix, boleto em processamento ou aprovação de parcelamento). |
| **Cancelado** | O pedido foi cancelado - por você ou pelo vendedor. |

## Status de entrega

O **status de entrega** mostra onde está fisicamente o seu pedido:

| Status | O que significa |
| :--- | :--- |
| **Preparando** | O vendedor está separando, produzindo ou conferindo os itens. |
| **Enviado** | O pedido saiu para entrega. |
| **A caminho** | O entregador está a um tempo estimado de você (aparece no mapa se disponível). |
| **Entregue** | O pedido foi entregue com sucesso. |
| **Pronto para retirada** | O pedido está disponível para você buscar no local combinado. |
| **Falha na entrega** | A entrega não pôde ser concluída. O vendedor entrará em contato. |

## Como visualizar os detalhes de um pedido

Clique em qualquer card de pedido para abrir os **detalhes**. Lá você vê:

| Seção | O que mostra |
| :--- | :--- |
| **Resumo** | Itens do pedido, quantidade, preços, frete, descontos e total. |
| **Pagamento** | Forma(s) de pagamento, parcelamento, status e botão de pagamento (se houver pendência). |
| **Entrega** | Endereço, tipo de entrega, status, entregador (se associado) e rastreamento (quando disponível). |
| **Histórico** | Linha do tempo com todos os eventos: pagamento, preparo, envio, entrega, cancelamentos. |
| **Anexos** | Comprovantes, fotos ou arquivos relacionados ao pedido. |

## Como pagar um pedido pendente

Se o status de pagamento está como **Pendente**, você pode finalizar o pagamento:

### Pedidos com Pix

1. Clique no card do pedido.
2. Clique em **Pagar via Pix**.
3. Escaneie o QR Code com o app do seu banco ou a copie.
4. Ao confirmar o pagamento, o status atualiza automaticamente para **Pago**.

### Pedidos com boleto

1. Clique no card do pedido.
2. Clique em **Ver boleto**.
3. Pague com o código de barras no seu banco ou caixa eletrônico.
4. A confirmação pode levar até 1 dia útil.

### Pedidos parcelados no cartão

1. Clique no card do pedido.
2. Clique em **Pagar com cartão**.
3. Complete a transação no checkout seguro do Mercado Pago.

> [i] O sistema tenta sincronizar o status automaticamente. Se demorar mais de alguns minutos, clique no botão de **revisar status** na tela de detalhes.

## Como confirmar o recebimento

Se a entrega foi marcada como **Entregue** mas você ainda não recebeu o pedido, ou quando a entrega foi feita sem confirmação automática (ex: retirada no local), você pode confirmar manualmente:

1. Abra os detalhes do pedido.
2. Clique em **Confirmar recebimento**.
3. O status atualiza imediatamente.

> [!] Confirmar o recebimento libera a possibilidade de avaliar o produto e também aciona o fluxo de troca/devolução.

## Como cancelar um pedido

Cancelamentos são permitidos apenas em determinadas situações. O botão **Solicitar cancelamento** aparece quando:

| Condição | Cancelamento permitido? |
| :--- | :--- |
| Status de pagamento: **Pendente** | Sim (cancelamento imediato) |
| Status de pagamento: **Pago**, sem envio ainda | Sim (solicitação, depende do vendedor) |
| Status de entrega: **Enviado**, **A caminho** ou **Entregue** | Não |

Se o cancelamento for permitido, você verá um botão na tela de detalhes com os motivos disponíveis:

| Motivo | Quando usar |
| :--- | :--- |
| **Comprei por engano** | Não quer mais o item |
| **Encontrei preço melhor** | Achou mais barato em outro lugar |
| **Atraso na entrega** | O prazo está fora do combinado |
| **Mudou de ideia** | Decisão própria |
| **Problema no pagamento** | Teve dificuldade com o método de pagamento |
| **Outro** | Qualquer outro motivo |

> [i] Você pode adicionar uma mensagem explicativa ao cancelar. O vendedor recebe a solicitação e analisa. O reembolso, se aplicável, é processado após a aprovação.

## Avaliações de pedidos

Depois que um pedido atinge o status **Pago**, um botão **Avaliar** aparece na listagem ou nos detalhes. Clique para deixar sua nota (1-5 estrelas) e um comentário sobre os itens. Veja mais em [Avaliações na Vitrine Online](./02-avaliacoes.md).

## Botões de ação rápida

Dependendo do status do pedido, botões diferentes aparecem:

| Botão | Quando aparece | O que faz |
| :--- | :--- | :--- |
| **Pagar via Pix/Boleto/Cartão** | Status de pagamento Pendente | Abre o checkout para finalizar o pagamento |
| **Revisar status do pagamento** | Status de pagamento Pendente | Tenta atualizar o status do pagamento |
| **Confirmar recebimento** | Status de entrega Enviado ou A caminho | Confirma que você recebeu o pedido |
| **Solicitar cancelamento** | Pedido elegível para cancelamento | Abre o formulário de cancelamento |
| **Solicitar troca ou devolução** | Status Pago + Entregue | Abre o formulário de troca/devolução |
| **Avaliar** | Status Pago | Abre o modal para deixar sua avaliação |
| **Ver detalhes** | Sempre disponível | Abre a tela completa do pedido |
| **Pagar diferença da troca** | Pedido de troca com saldo pendente | Abre o pagamento da diferença via Pix |

## Navegação entre pedidos

Na tela de detalhes, use os botões **Anterior** e **Próximo** para navegar entre pedidos sem sair da tela. Ou volte para a listagem clicando no botão **Voltar**.

## Problemas comuns

**O status do meu pedido não atualiza**
- O sistema tenta sincronizar automaticamente a cada alguns minutos. Clique em **Revisar status** para forçar a atualização.
- Se ainda não refletir a realidade, entre em contato com o vendedor diretamente pelo WhatsApp.

**Não consigo confirmar o recebimento**
- O botão só aparece quando o status de entrega permite (Enviado, A caminho, Pronto para retirada). Aguarde a atualização do status.

**O pedido aparece como Entregue mas não chegou**
- Aguarde alguns minutos - o vendedor pode ter atualizado antecipado.
- Verifique com familiares ou vizinhos se alguém recebeu.
- Abra um contato com o vendedor pelo WhatsApp ou entre em contato conosco.

**Não vejo o botão de cancelamento**
- Cancelamentos só são permitidos antes do envio. Se o pedido já foi despachado, entre em contato com o vendedor.

## Perguntas frequentes

**Quantos pedidos são mostrados por página?**
A listagem mostra **10 pedidos por página**, com navegação simples entre as páginas.

**Posso filtrar por período?**
Nesta versão, a filtragem é por status (abas). A busca por número também é disponibilizada.

**O pedido cancelado some da lista?**
Não - pedidos cancelados continuam visíveis na aba **Todos** com status Cancelado, para sua conexão ter histórico completo.

**Preciso confirmar recebimento se a entrega foi feita?**
Sim, confirmar garante que sua avaliação e eventuais trocas/devoluções funcionem corretamente. O sistema também tenta detectar a entrega automaticamente quando possível.
